# הלן – עוזר קולי בעברית, בלי אינטרנט

כאן נמצאים קובצי ההתקנה והמודלים להורדה. (קוד המקור לא נמצא כאן.)

## ⬇️ האפליקציה
**[להורדת הגרסה האחרונה](../../releases/tag/app)**

- `Helen-…apk` – הגרסה המלאה, עם מודל זיהוי דיבור מובנה (בערך 215MB).
- `Helen-…-lite.apk` – גרסה קלה בלי מודל (בערך 25MB). טוענים מודל מהטלפון בהגדרות ← שמיעה.

מורידים את הקובץ בטלפון, פותחים אותו ומאשרים "התקנה ממקורות לא ידועים" אם הטלפון שואל.
